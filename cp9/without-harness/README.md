# harness-lab

Laboratorio de pruebas mínimo en Python para probar un calculador de totales de carrito de compra con descuentos.

## Estructura

```
harness-lab/
├── requirements.txt      Dependencias del proyecto
├── src/cart.py           Lógica del carrito
└── tests/test_cart.py    Tests unitarios
```

## Instalación

```bash
pip install -r requirements.txt
```

## Ejecutar los tests

```bash
python -m pytest
```
