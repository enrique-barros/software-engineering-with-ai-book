# Prompt 1

Inicializa el repositorio de Git con las ramas main y develop. Añade el archivo .gitignore para un proyecto simple de web con solo HTML, CSS y JavaScript. No crees todavía la web, deja el repositorio solo con las ramas indicadas y el .gitignore.

# Prompt 2

Crea el código base de la aplicación en la rama main. Genera una web de convertidor de unidades (temperatura, distancia y peso) funcional y minimalista, dividida estrictamente en tres archivos: index.html, style.css y script.js. El diseño debe ser limpio y moderno, con el código y contenido justo y necesario, sin añadir nada innecesario.

# Prompt 3

Crea el archivo .github/workflows/opencode.yml para configurar un flujo de trabajo automatizado con GitHub Actions. Esto debe permitirme aplicar cambios en el código directamente desde GitHub utilizando el modelo gratuito Big Pickle.

# Prompt 4

Cámbiate a la rama develop e introduce un fallo a propósito en la fórmula de conversión de Celsius a Fahrenheit dentro del archivo script.js (por ejemplo, alterando la multiplicación o la suma para que devuelva un resultado incorrecto).

# Prompt 5

Sube el proyecto a un repositorio privado de GitHub llamado convertidor-unidades con las ramas main y develop actualizadas.
