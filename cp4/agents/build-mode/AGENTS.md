# FastAPI course repo

Single-file FastAPI learning project with no tests, no build tooling, and no CI.

## Dev server

& .\venv\Scripts\python -m uvicorn main:app --reload

## Virtual environment

- Python 3.14.3, already at venv\
- Activate: .\venv\Scripts\Activate.ps1
- All deps pre-installed in venv\
